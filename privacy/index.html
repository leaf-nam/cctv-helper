cctv-helper 개인정보처리방침

앱명: cctv-helper — CCTV 조사 시간 동기화 도우미 · 시행일: 2026년 10월 16일 · 버전 1.0

요약: cctv-helper는 회원가입·로그인·서버 전송이 없는 완전 오프라인 앱입니다. 사건·CCTV 시각·오프셋·메모·사진 경로는 이용자 기기 안에만 저장되며, 개발자를 포함한 제3자에게 전송·공유·위탁되지 않습니다.

1. 처리하는 정보 항목 및 이용 목적

앱은 아래 정보를 기기 내 저장(SharedPreferences + JSON)에만 사용합니다. 영상 원본 바이너리는 저장·전송하지 않습니다.

항목내용이용 목적
사건 정보사건 제목, 설명(예약 필드), 생성시각, 정렬 순서사건별 CCTV·기록 관리
CCTV 원천 정보CCTV 이름, 영상 내 표시시각(displayedAt), 실제 시각(actualAt), 계산된 오차(offsetMillis)시각 오프셋 계산 및 보정시각 표시
기록 정보영상 내 표시시각, 보정시각(correctedAt), 메모, 사진 파일 경로(photoPath)보정시각 기준 사건 기록·정렬
  • 계정 식별자(이메일·전화번호 등), 위치정보(GPS·지도), 광고 식별자는 수집하지 않습니다. (지도·검색·그래프 기능은 미구현입니다.)
  • 분석·광고 SDK, 원격 백엔드, 외부 서버 연동이 없습니다.

2. 기기 권한

권한사용 시점목적
카메라기록 작성 시 사용자가 직접 촬영을 선택한 경우에만현장 사진 첨부
사진 보관함(앨범)기록 작성 시 사용자가 직접 사진 선택을 한 경우에만사진 첨부

권한을 허용하지 않아도 사진 첨부 외의 모든 기능(사건·CCTV 등록, 오차 계산, 메모)을 사용할 수 있습니다. 사진은 기기 내 파일 경로만 기록되며 외부로 전송되지 않습니다.

3. 보유 및 파기

  • 모든 데이터는 이용자 기기에만 보관됩니다. 별도 보관기간을 두지 않으며, 앱 내에서 사건·CCTV·기록을 삭제하면 해당 항목이 기기 저장소에서 삭제됩니다.
  • 앱 삭제 시 기기 내 저장 데이터가 함께 삭제됩니다. 단, OS 차원의 기기 백업·복원 범위에 포함될 수 있으며 이는 OS 설정을 따릅니다.

4. 제3자 제공·처리위탁·국외이전

해당 없음. 서버 전송이 없으므로 제3자 제공, 처리위탁, 국외이전이 발생하지 않습니다.

5. 이용자의 권리

이용자는 앱 내에서 자신의 데이터를 직접 열람·수정·삭제할 수 있습니다 (사건 목록, CCTV 카드, 기록 시트). 별도 요청이 필요한 경우 아래 문의처로 연락하면 안내합니다.

6. 아동의 개인정보

앱은 아동을 대상으로 개인정보를 수집하지 않으며, 연령 확인을 위한 정보를 요구하지 않습니다.

7. 안전성 확보 조치

  • 네트워크 전송 자체가 없어 전송 구간 유출 위험이 없습니다.
  • 데이터는 OS가 제공하는 앱 전용 저장 영역(SharedPreferences)에 보관되며, 다른 앱이 임의로 접근할 수 없습니다.
