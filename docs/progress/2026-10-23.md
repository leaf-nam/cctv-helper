### 1.0.1 구현 (PR #29)
- **기록 메모 수정 (#30)**
  - 기록 항목에 수정 아이콘 추가, 기존 삭제 아이콘과 분리.
  - `메모 수정` 다이얼로그에서 기존 메모를 초기값으로 편집.
  - `저장`/`취소`, 빈 메모 허용, 변경이 없으면 저장하지 않음.
  - 저장 시 기존 `EventsProvider.updateMemo()` 사용.
- **CCTV 카드·기록 목록 접기/펼치기 (#31)**
  - 카드 헤더의 이름/화살표를 눌러 카드 전체 접기/펼치기.
  - 접힌 카드는 이름·오프셋 요약·기록 건수만 표시.
  - 기록 목록 헤더의 화살표로 기록 목록 접기/펼치기.
  - `AnimatedSize`로 카드 본문 접힘 애니메이션, 320dp·큰 글꼴 대응.
- **온보딩 도움말 줄바꿈 (#33)**
  - 공용 `WordWrapText` 추가: 공백 기준 단어를 `Wrap`으로 배치.
  - 튜토리얼 본문에 적용해 단어 중간이 잘리지 않도록 수정.
  - 접근성 라벨은 전체 문장을 유지(`Semantics` + `ExcludeSemantics`).
