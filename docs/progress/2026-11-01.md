## 한 일

### 시각 입력 편의 개선 (#36) — 리뷰 반영
- `GroupedDigitsInputFormatter` 추가: 숫자만 입력하면 날짜 `-`, 시간 `:`를 자동 삽입
  (`20261022` → `2026-10-22`, `140322` → `14:03:22`). 그룹이 차면 구분자를 미리
  보여 주고(`14` → `14:`), 구분자를 지우면 앞 숫자까지 함께 지운다.
- 최대 자릿수(날짜 8, 시간 6) 초과분과 숫자 외 문자는 무시(붙여넣기 포함).
- 검증 결과에 `incomplete` 상태 추가: 자릿수가 모자란 입력 중에는 경고하지 않고,
  범위를 벗어난 값(연 1900~2100, 월 1~12, 시 0~23, 분/초 0~59)에만 경고한다.
  미완성 안내는 포커스 아웃/제출 시에만 표시.
- 키보드를 숫자 키패드로 변경, 힌트 문구 갱신.
- 테스트: 마스크 포매터 단위 테스트 6개, 자동 구분자·미완성 무경고 위젯/단위 테스트 추가.

### macOS OCR 동작 확인
- `google_mlkit_text_recognition 0.17.1`은 android/ios만 지원하고 macOS 구현이 없다.
  macOS 빌드의 `GeneratedPluginRegistrant.swift`에도 ML Kit 항목이 없어
  `MissingPluginException`이 발생하고, 서비스가 이를 삼켜 `null`을 반환한다.
- 하드웨어 성능 문제가 아니라 **플러그인의 플랫폼 지원 범위** 문제임을 확인.
- 개발자 결정: 코드 변경 없이 iOS 시뮬레이터/Android 실기기에서 확인.
- 진단용으로 macOS Vision(`VNRecognizeTextRequest`) CLI를 임시로 만들어 실제
  캡처를 인식해 봤다. 결과: 메뉴바 캡처 `Fri Oct 30` + `) 9:11PM` →
  파서가 `21:11`은 추출했지만 날짜 `Oct 30`은 인식하지 못해 오늘 날짜로 대체됐다.

### OCR 영어 월 이름 파싱 (#38)
- 이슈 #38 등록(v1.1.0, S 규모).
- `TimestampParser`에 월 이름 토큰과 3가지 배치 패턴 추가:
  - 월-일(-연도): `Oct 30 9:11 PM`, `OCT.30.2026 21:11:05`, `Oct 30, 2026 09:05:00`
  - 일-월(-연도): `30-Oct-2026 21:11:05`, `30 OCT 2026`
  - 연-월-일: `2026 OCT 30 21:11:05`
  - 약어·전체 월 이름, 대소문자 무시.
- 연도가 없으면 fallback 날짜의 연도로 추정하고, fallback보다 하루 넘게 미래면
  작년으로 보정(`_inferYear`). 범위 초과·없는 날짜는 후보 제외.
- 메뉴바 캡처(`Fri Oct 30\n) 9:11PM`)가 `2026-10-30 21:11:00 (date+time)`로
  인식되는 것을 확인(기존에는 오늘 날짜 fallback).
- 테스트: 영어 월 이름 9개 추가(총 20개).
