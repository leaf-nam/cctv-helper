## 한 일

### 이슈·브랜치

- `#36` 시각 직접 입력 범위 검증(7777777 등) 등록 (v1.1.0)

- `release/1.1.0`에서 `feat/v1-1-0` 작업 브랜치 생성

### 사진 저장 인프라 (#26)
- `PhotoStorageService` 추가: 앱 문서 디렉터리 `cases/<caseId>/sources/<sourceId>/`
  구조로 원본 복사, 상대 경로 반환, 절대 경로 마이그레이션, 파일/폴더 정리, 용량 계산.
- `TimelineEvent.photoPath` → `photoPaths` 목록 확장. `fromMap()`은 기존 단일
  경로를 목록으로 승격하고 `toMap()`은 두 키를 함께 기록.
- `EventsProvider` 시작 시 절대 경로 마이그레이션, 원본 유실 시 placeholder 정리.
- 사건/CCTV/기록 삭제 시 사진 파일 정리(`CasesProvider`, `SourcesProvider`,
  `EventsProvider`, `PhotosProvider`).

### OCR 시간 인식 (#27)
- `OcrService` 계약 + ML Kit 구현(`korean` → `latin` 재시도) + 웹 스텁.
- `TimestampParser`: `yyyy-MM-dd HH:mm:ss`, `yyyy/MM/dd`, `MM/dd/yyyy`,
  AM/PM, 한글 단위, 14자리 압축, 전각 문자 지원. 범위 초과·없는 날짜는 후보 제외.
- 기준 촬영 시트: 실제시간/CCTV 사진 2장 OCR → 후보 표시 → 사용자 수정 → 적용 시
  오프셋 저장 + 기준 사진 보관.
- 기록 시트·사진 추가 시트에 `사진에서 시각 인식` 추가 (자동 확정 금지).

### 사진 보관함 (#28)
- `CasePhoto` 모델 + repository/provider + `casePhotos` 저장 키.
- `/case/:id/photos` 화면: CCTV별 그룹·색상·오프셋·장수, 보정시각 순 그리드,
  카메라/앨범 추가, 유형/메모/OCR, 상세 보기·메모 수정·삭제, CCTV 필터, 빈 상태.
- 사건 상세 앱바에 사진 보관함 진입 버튼 추가.

### 통합 타임라인 (#7)
- `TimelineEntry`가 기록+사진을 보정시각 오름차순으로 병합.
- `/case/:id/timeline` 화면: 날짜 헤더(건수), 시간축, CCTV 색상/필터, 썸네일,
  오프셋 배지, 상세 시트, `ListView.builder`(100건 이상 대응).
- 사건 상세 앱바에 타임라인 진입 버튼 추가.

### 표시·입력 개선 (#35, #36)
- 공용 `DateTimeText`/`DateTimeInlineText`: 날짜 `bodyMedium`+, 시간 20sp/16sp,
  굵기 600, 고정폭 숫자, 스크린리더 문장 제공.
- `dateInputFormatters`/`timeInputFormatters` + `validateDateInput`/
  `validateTimeInput` 추가. 인라인 입력에서 오류 문구 표시 및 저장 차단.

### 배포 설정·문서
- `path_provider`, `google_mlkit_text_recognition` 의존성 추가.
- iOS 배포 타깃 15.0 → 15.5 (ML Kit 요구).
- `pubspec.yaml` 버전 `1.1.0+3`.
- `docs/context/model_spec.md`, `docs/architecture/architecture_spec.md`,
  `docs/features/feature_spec.md`, `docs/releases/1.1.0.md` 갱신.

## 주요 결정 사항
- v1.1.0 이슈 6건은 의존 관계가 강해 **단일 기능 브랜치·PR 1개**로 묶는다
  (개발자 확인 완료).
- 사진은 원본을 앱 문서 디렉터리로 복사하고 모델에는 상대 경로만 저장한다.
- OCR은 온디바이스(ML Kit)만 사용하며 웹에서는 수동 입력으로 대체한다.
- OCR 결과는 자동 확정하지 않고 사용자 확인 후에만 저장한다.
- 기록·사진·타임라인의 모든 시각 표시는 `DateTimeText` 계열로 통일한다.
