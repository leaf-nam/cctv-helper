## 주요 결정 사항
- 1.0.1은 시간 입력·표시 UX와 튜토리얼까지로 제한
- 시각 편집은 live-apply 대신 draft + 적용/닫기로 변경 (오입력 방지)
- 날짜 선택은 연도·월 → 일 → 시·분 순서, 시간은 24시간제
- OCR은 온디바이스 ML Kit + 사용자 확인/수정 필수, 수동 입력 fallback 유지
- 사진 저장 인프라(#26)를 OCR·아카이브·타임라인의 선행 작업으로 둠
