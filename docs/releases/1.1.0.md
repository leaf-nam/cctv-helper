# 1.1.0

OCR 시간 인식, 사진 보관함, 통합 보정 타임라인을 추가하고 시각 표시·입력 품질을
끌어올린 기능 릴리스.

## 변경점

- **사진 파일 로컬 보관 (#26)**
  - 사진을 OS 캐시가 아닌 앱 문서 디렉터리(`cases/<caseId>/sources/<sourceId>/`)에 복사해 보관
  - 모델에는 상대 경로만 저장, 기존 절대 경로 데이터는 시작 시 자동 마이그레이션
  - 원본이 사라진 경로는 placeholder로 정리, 사건/CCTV/기록 삭제 시 파일 정리
  - `TimelineEvent.photoPath` → `photoPaths` 목록으로 확장(기존 데이터 호환 읽기)
- **OCR 시간 자동 인식 (#27)**
  - 실제시간 화면 + CCTV LIVE 화면 사진 2장으로 기준 시각·오프셋 자동 채우기
  - 녹화장면 사진에서 CCTV 시각을 인식해 보정 실제시간 즉시 산출
  - 온디바이스 ML Kit 사용(서버 전송 없음), 인식 결과는 사용자 확인·수정 후 적용
  - `yyyy-MM-dd HH:mm:ss`, `yyyy/MM/dd`, `MM/dd/yyyy`, AM/PM, 한글 단위,
    14자리 압축 표기 지원. 25시·2월 30일 등 범위 초과 값은 후보에서 제외
- **사건·CCTV별 사진 보관함 (#28)**
  - 사건 상세 → 사진 보관함, CCTV별 그룹·색상·장수·오프셋 표시
  - 카메라/앨범 추가, 유형(기준/장면/기타), 메모, OCR 시각 인식, 상세 보기·삭제
  - 보정 실제시간 순 정렬, CCTV 필터, 빈 상태 안내
- **통합 보정 타임라인 (#7)**
  - 사건의 모든 CCTV 기록·사진을 보정 실제시간 기준으로 통합 정렬
  - 날짜별 그룹, 시간축, CCTV 범례/필터, 썸네일, 오프셋 배지
  - 항목 탭 시 상세 시트, 100건 이상에서도 `ListView.builder`로 스크롤 성능 유지
- **시각 표시 가독성 (#35)**
  - 공용 `DateTimeText`로 날짜·시간 크기 통일: 시간 20sp·굵기 600·고정폭 숫자
  - 기준 카드·시간 확인·기록 목록·기록 시트·사진 보관함·타임라인 적용
- **시각 직접 입력 편의·검증 (#36)**
  - 숫자만 입력하면 날짜 `-`, 시간 `:`를 자동 삽입(`20261022` → `2026-10-22`,
    `140322` → `14:03:22`). 두 칸이 차면 구분자가 먼저 보인다(`14` → `14:`)
  - 구분자를 지우면 앞 숫자까지 함께 지워 자연스럽게 수정, 최대 자릿수 초과분은 무시
  - 경고는 범위를 벗어날 때만(연 1900~2100, 실제 존재하는 날짜, 시 0~23, 분/초 0~59)
  - 입력 중에는 경고하지 않고, 포커스를 잃을 때만 미완성 안내
  - 유효하지 않은 값은 저장 차단
