# 1.1.1

모달 사용성, 사진 보기, CCTV 색상 구분, OCR 후보 선택을 다듬은 UX 개선 릴리스.

## 변경점

- **CCTV별 색상 일관 적용 (#43)**
  - 사건 상세 `CctvCard` 헤더와 카드 안 기록 목록에도 CCTV 색 점을 표시
  - 사진 보관함·통합 타임라인과 동일한 `SourcePalette`(사건 내 CCTV 순서) 사용
  - 색만으로 구분하지 않도록 이름·아이콘 등 기존 정보는 유지
- **한 사진에서 두 시각 후보 선택 (#42)**
  - `TimestampParser.candidates()`가 한 글에 나온 여러 시각을 각각 후보로 추출
  - 기준 입력 시트에 `한 장에 두 시각이 보이나요?` 모드 추가:
    사진 한 장을 인식해 후보를 `실제시간`/`CCTV`에 각각 지정
  - 슬롯별 인식에서도 후보가 2개 이상이면 칩으로 골라 적용
  - 같은 사진을 두 슬롯에 써도 보관함에는 한 번만 저장
  - 인식 결과는 자동 확정하지 않고 `적용` 전 확인·수정 유지
- **모달 하단 시스템 바 겹침 제거 (#44)**
  - 공용 `modalSheetPadding()` 추가: `viewInsets`(키보드)와
    `viewPadding`(내비게이션 바·홈 인디케이터) 중 큰 값을 하단 여백에 반영
  - 기준 OCR, 기록 추가, 사진 추가, 시각 편집, 사진 상세 시트에 일괄 적용
  - 키보드가 열린 상태에서도 적용/저장 버튼을 탭할 수 있음
- **메모 첨부 사진 OCR 동작 (#45)**
  - 기록 시트에서 사진을 이미 첨부했으면 다시 고르지 않고 그 사진으로 인식
  - 사진이 없을 때만 촬영/앨범 선택 시트 표시
  - 버튼 라벨이 `사진에서 시각 인식` ↔ `첨부 사진에서 시각 인식`으로 상태 반영
- **사진 탭 시 전체화면 보기 (#46)**
  - 사진 보관함에서 사진을 누르면 바로 전체화면 뷰어(핀치 줌·팬, 닫기)
  - 뷰어에서 `정보` 버튼으로 기존 상세 시트(메모 수정·삭제) 진입
  - 사진이 없거나 깨진 경우 안내 표시. 다운로드/공유는 후속 과제로 분리
