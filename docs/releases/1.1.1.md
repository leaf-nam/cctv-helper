# 1.1.1

모달 사용성, 사진 보기, CCTV 색상 구분, OCR 후보 선택을 다듬은 UX 개선 릴리스.

## 변경점

- **CCTV별 테마 색상 선택 (#43)**
  - 같은 채도·명도에서 색상만 나눈 테마 색 **20개** 지원
  - CCTV 카드의 색 점을 눌러 CCTV별 색을 선택·저장(`CctvSource.colorIndex`)
  - 사건 상세 카드·기록 목록·사진 보관함·통합 타임라인에 동일한 색 적용
  - 선택 전에는 사건 내 CCTV 순서로 기본 색 배정, 이름·아이콘 정보는 유지
- **한 사진으로 실제시간·CCTV 시각 지정 (#42)**
  - 기준 입력 시트의 사진 입력을 **한 곳**으로 통합 (슬롯별 촬영/앨범 제거)
  - 사진 한 장에서 `TimestampParser.candidates()`로 여러 시각 후보 추출
  - 인식 후 각 후보를 `실제시간`/`CCTV`에 지정하고, 아래 슬롯 카드에서 확인·직접 수정
  - 같은 후보를 양쪽에 동시 지정하지 못하게 하고 필요하면 교체
  - 같은 사진을 두 슬롯에 써도 보관함에는 한 번만 저장
  - 인식 결과는 자동 확정하지 않고 `적용` 전 확인·수정 유지
- **오프셋 상세 표기 개선**
  - 통합 타임라인·사진 상세의 오프셋에서 `(120000ms)` 원값 표기 제거
  - `+0일 0시 2분 0초`처럼 일·시·분·초로 표기 (`TimeCalcService.formatOffsetFull`)
- **모달 하단 시스템 바 겹침 제거 (#44)**
  - 공용 `modalSheetPadding()` 추가: `viewInsets`(키보드)와
    `viewPadding`(내비게이션 바·홈 인디케이터) 중 큰 값을 하단 여백에 반영
  - 기준 OCR, 기록 추가, 사진 추가, 시각 편집, 사진 상세 시트에 일괄 적용
  - 키보드가 열린 상태에서도 적용/저장 버튼을 탭할 수 있음
- **메모 첨부 사진 OCR 동작 (#45)**
  - 기록 시트에서 사진을 이미 첨부했으면 다시 고르지 않고 그 사진으로 인식
  - 사진이 없을 때만 촬영/앨범 선택 시트 표시
  - 버튼 라벨이 `사진에서 시각 인식` ↔ `첨부 사진에서 시각 인식`으로 상태 반영
- **사진 탭 시 전체화면 보기 (#46)**
  - 사진 보관함에서 사진을 누르면 바로 전체화면 뷰어(핀치 줌·팬, 닫기)
  - 뷰어에서 `정보` 버튼으로 기존 상세 시트(메모 수정·삭제) 진입
  - 사진이 없거나 깨진 경우 안내 표시. 다운로드/공유는 후속 과제로 분리
