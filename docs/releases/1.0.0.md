# 1.0.0

첫 정식 릴리스 — 여러 CCTV 영상의 어긋난 시각을 맞춰 조사하는 시간 동기화 도우미.

## 변경점

- CCTV 현재시간 입력: 영상 표시시각 + 실제 현재시간 쌍 입력 (스테퍼·직접 선택, live-apply)
- 오차 계산: 표시시각–실제시각 오프셋(±ms) 자동 계산, 보정시각 = 표시시각 + 오프셋
- CCTV 이벤트 입력: 메모 + 카메라 촬영·앨범 사진 첨부, 생성 시 보정시각 자동 확정
- 사건별 CCTV 관리: 사건·CCTV 추가, 이름 변경·순서 변경·등록일자·삭제, 모두 로컬 저장
- 완전 오프라인: `SharedPreferences` + JSON 기기 내 저장, 서버·계정·분석 없음
- 배포용 개인정보처리방침 페이지: `privacy/index.html` (정적 단일 파일)
