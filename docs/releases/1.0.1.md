# 1.0.1

시간 입력·표시 UX를 다듬고, 첫 실행 튜토리얼을 추가한 유지보수 릴리스.

## 변경점

- 시각 표시를 `날짜(yyyy-MM-dd)` / `시간(HH:mm:ss)` **2줄**로 분리하고 초를 항상 표시
  - 좁은 화면(320dp)에서는 `입력`/`지금` 버튼을 아이콘으로 축약해 잘림 방지
- 날짜 직접입력 버그 수정
  - `yyyy-MM-dd`, `yyyy.MM.dd`, `yyyy/MM/dd`, `yyyyMMdd`, `yyyy년 MM월 dd일` 지원
  - 2월 30일·13월 등 존재하지 않는 날짜 거부
  - `flutter_localizations` + `ko` 로케일로 날짜 선택기 라벨·입력 형식 한국어화
- 시각 입력 시트를 **draft + 적용/닫기**로 분리
  - `적용`에서 한 번만 저장, `닫기`는 변경 사항 확인 후 버림
- 스테퍼(±1일/1시간/10분/1분/10초/1초)를 길게 누르면 연속 증감
- 연도 선택 단계에서 12개월 그리드를 함께 보여 줘 월을 바로 선택
- Android 내비게이션 바·홈 인디케이터와 바텀시트/하단 버튼 겹침 방지
- 첫 실행 튜토리얼 4단계 추가 + 사건 목록에서 다시 보기
- 기록 시트의 영상 시각도 날짜/시간 2줄 표시
