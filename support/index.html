cctv-helper 고객지원

여러 CCTV 영상의 어긋난 시각을 맞춰 하나의 흐름으로 조사하는 시간 동기화 도우미입니다. 아래에서 기능 안내와 자주 묻는 질문을 확인하실 수 있습니다.

주요 기능

현재시간 입력

CCTV 영상에 표시된 시각과 실제 현재시간을 쌍으로 입력합니다. CCTV 추가 시 실제 시각은 현재시간으로 자동 초기화되며, [지금] 버튼과 ±1시간/10분/1분 스테퍼 또는 직접 선택으로 조정할 수 있습니다.

오차 계산

표시시각과 실제시각의 차이(±ms)를 자동 계산합니다. 보정시각 = 표시시각 + 오프셋이며, 시간 표시는 보정·원본·오프셋 3요소를 함께 보여줍니다.

이벤트 입력

영상에서 확인한 장면을 메모와 사진(카메라 촬영·앨범 선택)으로 기록합니다. 보정시각은 기록 생성 시 오프셋으로 자동 확정되며, 사건별 보정시각 순으로 정렬됩니다.

사건별 CCTV 관리

사건별로 CCTV를 추가·관리합니다. 사건과 CCTV 모두 이름 변경·순서 변경이 가능하며, 모든 데이터는 기기 안에 저장됩니다.

자주 묻는 질문

오차는 어떻게 계산되나요?

실제시각 − 표시시각을 밀리초(ms) 단위로 계산합니다. 두 시각이 모두 입력되어야 계산되며, 하나라도 비어 있으면 "미계산"으로 표시됩니다.

보정시각이란 무엇인가요?

영상 내 표시시각에 오프셋을 더한 시각(표시시각 + 오프셋)입니다. 기록 작성 시점의 오프셋으로 확정되므로, 이후 CCTV 시각을 수정해도 이미 작성된 기록의 보정시각은 바뀌지 않습니다.

사진과 영상은 어디에 저장되나요?

영상 원본 바이너리는 저장하지 않습니다. 기록에 첨부한 사진은 기기 내에만 보관되고 사진 파일 경로만 기록됩니다. 외부 서버로 전송되지 않습니다.

인터넷 없이 사용할 수 있나요?

네. 회원가입·로그인·서버 전송이 없는 완전 오프라인 앱으로, 모든 기능이 인터넷 연결 없이 동작합니다.

카메라·사진 권한을 허용하지 않아도 되나요?

네. 사진 첨부 외의 모든 기능(사건·CCTV 등록, 오차 계산, 메모)은 권한 없이 사용할 수 있습니다.

데이터를 삭제하려면 어떻게 하나요?

앱 내에서 사건·CCTV·기록을 직접 삭제할 수 있습니다. 앱을 삭제하면 기기 내 저장 데이터가 함께 삭제됩니다.
